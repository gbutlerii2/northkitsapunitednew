## Welcome

The admin panel lets approved volunteers change the North Kitsap United website from a web browser, with no coding and no waiting: every change goes live the moment you click **Save**.

This guide walks through every part of the admin panel, in the order a new admin usually learns it. Each section says what the feature is for, then gives numbered steps. Screenshots show what you should see. You can open this guide at any time from **User guide** in the admin menu.

**What you can do as an admin**

- Change the words, pictures and buttons on any page, right on the page itself
- Write and publish News posts
- Upload and manage images
- Choose who receives form submissions by email, and set up the account the website sends email from
- Turn the Zeffy online-payment option on or off on the Donate page
- Add or remove other admins, and change your own password
- Copy all admin content from the test site to the live site (used once, at go-live)

**Two copies of the site**

| Site | Address | Used for |
| --- | --- | --- |
| Live site | https://www.northkitsapunited.com/admin-panel | Real changes the public sees (after go-live) |
| Test site | https://northkitsapunitednew.netlify.app/admin-panel | Practice and trying out new features |

Each copy has its own logins and its own content. A change made on the test site does not appear on the live site. Practice on the test site first if you are unsure.

**Safety net:** every page edit is kept in History (the last 15 versions), and any page can be put back to its original text. You cannot permanently break a page by editing it.

*Screenshots in this guide were taken on a practice copy of the site with sample names and addresses (example.org), so your screens will show NKU's real content.*

## 1. Logging in and the Dashboard

You log in at the site address followed by **/admin-panel**, using the email and password an existing admin gave you.

**To log in**

1. Open https://www.northkitsapunited.com/admin-panel (or the test site address).
2. Type your **Email** and **Password**, then click **Log in**.
3. The first time, a yellow box says *Please change your password*. Click **Change it now** and follow section 7. Do this before anything else.

![The admin login page](/admin-assets/guide/01-login.webp)

You stay logged in for 8 hours, then you are asked to log in again. After 8 wrong passwords in a row, logins for that email are locked for 15 minutes; wait, then try again.

**The admin menu**

The dark green menu on the left (across the top on a phone) is how you move around:

| Menu item | What it is for | Guide section |
| --- | --- | --- |
| Dashboard | Start page with counts and a short how-to | this section |
| User guide | This guide | |
| Edit pages | List of every page, with edit and reset buttons | 3 |
| News | Write and manage News posts | 4 |
| Images | Upload and manage pictures | 5 |
| Forms & emails | Email settings, Zeffy, Tracker, form log | 6 |
| Users & password | Your password, and who can log in | 7 |
| Copy content | Copy everything from one site to the other (go-live) | 8 |
| View site | Opens the public website in edit-ready mode | 2 |

**The Dashboard** shows three cards: how many page sections have been edited, how many News posts are live (and drafts), and a shortcut to upload images. Click any card to jump to that area. Below the cards is a short reminder of how page editing works, and a **User guide** button.

![The Dashboard with the admin menu on the left](/admin-assets/guide/02-dashboard.webp)

**To log out**, click **Log out** at the bottom of the left menu (bottom of the page on a phone), or in the green bar at the bottom of any website page. Always log out on a shared computer.

## 2. Editing a page on the website

You edit a page by opening it on the website while logged in and typing straight onto it, the way you would in a word processor.

**Start editing**

1. While logged in, open any page of the site (use **View site** in the admin menu, or **Edit on page** in Edit pages).
2. A green **NKU Admin** bar appears at the bottom of the screen. Click **Edit this page**.
3. A message says *Editing on. Click any text to change it.* Editable areas get a light outline when you point at them.

The green bar before editing:

![Green NKU Admin bar with Edit this page](/admin-assets/guide/editbar.webp)

The same bar while editing, with History, Cancel and Save:

![Green bar while editing](/admin-assets/guide/editbar-editing.webp)

**Change text**

- Click any heading, paragraph, list or button label and type.
- Select some words to show the formatting toolbar: **B** (bold), *I* (italic), U (underline), the link button (add or change a link), **Unlink**, and **Clear** (removes bold, italic and so on).
- To make a link: select the words, click the link button, paste the web address, press Enter.
- The big title band at the top of each page is editable too.

![Formatting toolbar above selected text](/admin-assets/guide/format-toolbar.webp)

**Move, add, copy or delete a block** (a block is a paragraph, heading, picture, list item or button)

1. Point at the block. A small handle appears beside it.
2. Drag the six-dot handle up or down to move the block.
3. Click **+** to add something below it. Choose **Paragraph**, **Heading**, **Text card** (a white box with a heading and text), **Logo card**, **Image** or **Button**.
4. Click the copy button to duplicate the block, or the trash button to delete it. A delete shows an **Undo** button for a few seconds.
5. Inside a card, the buttons labeled **Card** copy or delete the whole card instead of one block.

The handle beside a paragraph (drag, +, copy, delete, and the Card buttons):

![Block handle beside a paragraph](/admin-assets/guide/block-handle.webp)

The menu that opens from **+**:

![Add below menu](/admin-assets/guide/add-menu.webp)

The handle stays in place while you move the mouse over to it, so you have time to reach it.

**Pictures**

- **Replace a picture:** drag a photo from your computer onto it, or click it and choose **Replace…**.
- **Add a picture:** drag a photo onto a paragraph (it goes after that paragraph) or onto a *Photo to come* box (it fills the box).
- **Size:** click the picture and choose **S**, **M**, **L** or **Full**.
- **Description:** click the picture and choose **Description**. Type what the picture shows, for visitors who use screen readers. Every picture should have one.
- **Remove:** click the picture and choose **Delete**.
- **Logo cards:** click the **[Logo]** box (or drop an image onto it) to add the logo.

![Picture options: Replace, Description, sizes and Delete](/admin-assets/guide/image-options.webp)

**The banner and footer** are shared by every page. Click the header banner while editing any page and choose **Replace…** to change it everywhere at once.

**Buttons:** add one with **+** then **Button**. Type its text, then select the text and click the link button to set where it goes.

**Save or cancel**

- Click **Save** in the green bar. The message *Saved. Your changes are live.* means the public can see them now.
- Click **Cancel** to throw away everything since you clicked Edit this page.
- If you try to leave with unsaved changes, the site warns you first.
- While editing, forms on the page do not send, so you cannot submit a test donation by accident.

![Saved. Your changes are live.](/admin-assets/guide/saved.webp)

**History and going back**

1. Click **History** in the green bar.
2. The list shows earlier saved versions (up to 15), with date, time and who saved them.
3. Click **Restore** beside a version to bring it back, or **Reset to original** to return to the text the site was built with. Your current version is kept in History either way, so this is safe to try.

History is listed by section: *header* (the shared banner), *hero* (the title band), *main* (the page body) and *footer*. Each section has its own Restore and Reset buttons, so you can undo one part without touching the others.

![Page history window](/admin-assets/guide/history.webp)

**The yellow "site was updated" warning**

Once a page is edited here, the website shows your saved copy instead of the built-in text. If the web developer later changes that page, admins see a yellow warning at the top of it. The warning offers three choices:

- **See the built version**, to compare the developer's new version with yours
- **History / Reset**, to drop your edits and use the new version (Reset to original)
- **Mark as up to date**, if your edits already include what changed

If you are unsure, ask the web developer before choosing.

**What you cannot change here**

- The top menu buttons (FAQ, Partners, Donate and so on)
- Background patterns and the green banner artwork
- Page titles that show in Google search results

Ask the web developer for these.

## 3. Edit pages list

**Edit pages** lists every page of the site and shows which ones have admin changes, so you can find a page quickly or undo all edits to it.

![Edit pages list, with History marked Edited](/admin-assets/guide/edit-pages.webp)

- **Status: Original** means the page shows its built-in text.
- **Status: Edited** means it shows saved admin changes, with the date, time and who saved last.
- **Edit on page** opens that page with editing already switched on.
- **Reset to original** (only on edited pages) puts the whole page back to its built-in text. You are asked to confirm first, and the edited version stays in that page's History.

## 4. News posts

News posts are short updates. All of them appear, newest first, on the **News** page (in the About menu), and the newest two also appear on the Home page. Each post also gets its own page at /news/ followed by its web address.

**Write a new post**

1. Admin menu, **News**, then **+ New post**.
2. **Title**: the headline.
3. **Date**: today is filled in. Change it to back-date a post; posts are listed by this date.
4. **Web address**: leave empty and it is made from the title (for example *spring-cleanup-day*). Only change it if you need a shorter address.
5. **Short summary**: one or two sentences shown in the News list.
6. **Main image**: drag a photo onto the box, or click it to choose one. Then type a description of the picture in the box below it. **Remove image** takes it off.
7. **Story**: the body of the post. The toolbar above it has Paragraph, Heading (H2), Subheading (H3), Bold, Italic, Underline, bulleted and numbered lists, Quote, Add link, Remove link, Image, YouTube video, Undo and Redo. You can also paste text from Word or an email; extra formatting is cleaned up.
8. Tick **Published (visible on the site)** to make it public, or leave it unticked to save a draft.
9. Click **Save**. The message says either *The post is live* or *Saved as a draft*.

![Writing a News post](/admin-assets/guide/news-edit.webp)

**Edit, view or delete a post**

The News list shows every post with its date and a **Live** or **Draft** label.

![News list with Live and Draft posts](/admin-assets/guide/news-list.webp)

- **Edit** opens the post. Make changes and click **Save**.
- **View** opens the post on the public site.
- To hide a post without deleting it, edit it, untick **Published** and save.
- **Delete** removes the post for good after you confirm. This cannot be undone, so unpublish instead if you might want it back.

## 5. Images

**Images** is the site's picture library: everything uploaded through the admin panel is stored here.

![Images library](/admin-assets/guide/images.webp)

- **Upload:** drag photos onto the box at the top, or click the box to choose files. JPG, PNG, GIF and WebP are accepted, and large photos are shrunk automatically, so you can upload straight from a phone or camera.
- **Copy link:** copies the picture's web address, to paste somewhere else (for example an email or a News post link).
- **Delete:** removes the picture after you confirm. Any page or post still using it will show a broken image, so check first.

You do not have to upload here before editing. Dropping a photo onto a page or into a News post uploads it to this library automatically.

## 6. Forms & emails

**Forms & emails** controls what happens when a visitor fills in a form on the site: who gets an email copy, which account sends it, whether it also goes to the NKU Tracker, and how online giving through Zeffy works.

The colored box at the top tells you the state at a glance. Green, *Email sending is on*, means emails are going out. Yellow, *Email sending isn't set up yet*, means you need to fill in the sending account. A red box describes a problem to fix.

![Top of the Forms & emails page](/admin-assets/guide/forms-top.webp)

**Sending account (the email the website sends from)**

For NKU this is the Gmail account **nku@rotaryknk.org**. The website signs in with a Google **App Password**, a special 16-letter password just for the website. Never use the account's normal Google password.

1. Sign in to Google as nku@rotaryknk.org and turn on 2-Step Verification if it is not on.
2. Go to myaccount.google.com/apppasswords and create an App Password (name it, for example, *NKU website*). Copy the 16 letters.
3. In the admin panel, fill in **Account email** (nku@rotaryknk.org) and paste the **App Password**.
4. **"From" line** is optional. It sets the name people see, for example *North Kitsap United &lt;nku@rotaryknk.org&gt;*.
5. Leave **Mail server** alone unless you use a non-Gmail account.
6. Click **Save sending account**.

![Sending account card](/admin-assets/guide/sending-account.webp)

The password is stored encrypted and is never shown again, even to admins. To change it, type a new one and save; leave the box empty to keep the saved one. **Remove saved account** deletes it. If you think the App Password has leaked, delete it in the Google account and make a new one.

**NKU Tracker switch**

**Send form submissions to the NKU Tracker** is on by default, so every form goes to the Tracker (nku-tracker.com) and to email. Turn it off to send forms to email only. The campaign figures on the Home page still come from the Tracker either way.

![NKU Tracker switch](/admin-assets/guide/tracker.webp)

**Zeffy (online giving)**

Zeffy is the free online payment service donors can use from the **Donate Now** form on the Donate page.

- **Use Zeffy for "Donate Now"** (on by default) is the first item in the Zeffy card. It decides whether donors pay online through Zeffy or are contacted by NKU about payment. Click the page's **Save** button after changing it.
    - **On:** after filling in the Donate Now form, the donor is sent to Zeffy to pay by card or bank transfer.
    - **Off:** the Donate Now form has no Zeffy buttons and does not mention Zeffy. It has one green **Send** button, and tells the donor the form goes to the North Kitsap United team and someone will contact them about payment, like the other Donate forms. After sending, the donor sees a thank-you message and stays on the site. The Pledge form's payment choice "Card or bank transfer (EFT) through Zeffy, monthly or quarterly" also changes to "Cash or bank transfer, monthly or quarterly". The save message adds *Zeffy is off: Donate Now shows a Send button.*
- **Zeffy link for card** and **Zeffy link for bank transfer (EFT):** paste the public web addresses of NKU's Zeffy donation forms. If only one is filled in, it is used for both. No Zeffy password is needed. The links are kept while Zeffy is off, ready for when you turn it back on.
- With Zeffy on and no links set, a yellow *No Zeffy links yet* note appears. The Tracker's own Zeffy links are then used if the Tracker is on; if the Tracker is off too, donors are told online giving isn't available yet.

**Who gets the forms**

1. In **All forms**, type the email addresses that should get a copy of every form, separated by semicolons, for example *treasurer@example.org; chair@example.org*.
2. If this box is empty, forms go to nku@rotaryknk.org.
3. Under **Different people for one form** (optional), fill in a box to send that one form to its own list instead. Leave a box empty to use the All forms list. The forms are: Online Donation, Gift Notice, Pledge, Donation Question and In-Kind Donation (Donate section), and Contact, Volunteer and Updates Signup.
4. Click **Save**.

![Who gets the forms](/admin-assets/guide/recipients.webp)

Each email's subject is the form name, a dash, and the person's name (for example *Pledge - Jane Smith*), which makes mail filters easy. Each field is on its own line, and clicking **Reply** answers the person who filled in the form.

**Send a test email**

Type an address (yours is filled in) and click **Send test**. A sample *Pledge* email arrives within a minute or two. Check the spam folder if it does not. The button is greyed out until a sending account is saved.

![Send a test email](/admin-assets/guide/test-email.webp)

**Recent submissions**

The bottom of the page lists the latest form submissions made through the website (the last 1,000 are kept). Each line shows the form, the person, the time, and whether the email went out (*emailed to 2*, *email failed* or *not emailed*). Click a line to see every field. This is your backup: nothing is lost even if email is not working yet.

## 7. Users & password

**Users & password** is where you change your own password and decide who else can log in. Every admin has the same powers, so only add people you trust.

![Users & password page](/admin-assets/guide/users.webp)

**Change your password**

1. Type your **Current password**.
2. Type a **New password** twice. It must be at least 10 characters, with letters and numbers.
3. Click **Change password**. The message *Password changed.* confirms it.

**Add an admin**

1. Under **Add a person**, type their **Email**, their **Name** (optional) and a **Starting password** (at least 10 characters).
2. Click **Add person**.
3. Give them the address of the admin panel, their email and the starting password privately (a phone call or text, not a group email). They are asked to change it when they first log in.

**Remove an admin**

Click **Remove** beside their email and confirm. They can no longer log in. You cannot remove yourself, so there is always at least one admin.

**Forgotten password**

There is no "forgot password" email. Another admin removes the person and adds them again with a new starting password. If no admin can log in at all, ask the web developer to reset the first admin account.

## 8. Copy content (go-live)

**Copy content** copies everything made in the admin panel from one copy of the site into the one you are logged in to. It is used at go-live to bring the test site's work onto the live site, and afterwards to refresh the test site with live content.

It copies page edits and their history, News posts, images, admin accounts, form email settings, the sending account and recent form submissions. Items with the same name are replaced; items that only exist on the receiving site are kept. The other site is only read, never changed.

**To copy**

1. Log in to the site you want to copy **into**.
2. Admin menu, **Copy content**. A green line says *Copying is switched on for this site*. If it says copying is off, the web developer needs to finish the setup first.
3. Check **Copy from**. It is filled in with the other site's address.
4. Click **Copy everything into this site** and confirm.
5. Wait for the progress bar to finish. It ends with *Done. Copied N items.* Read any red warnings below it; the usual one is an admin who had not logged in to the test site before the copy and has to be added again.
6. Check a few pages, the News page and Images.

![Copy content page](/admin-assets/guide/copy-content.webp)

If it stops partway, nothing already copied is lost. Click the button again to finish. You can run it as many times as needed, for example once to test and again just before switching the domain.

The full go-live order (which the web developer follows) is in the GO-LIVE checklist in the site's code repository.

## 9. Troubleshooting

| Problem | What to do |
| --- | --- |
| I can't log in | Check the email spelling and Caps Lock. After 8 wrong tries, wait 15 minutes. Still stuck: ask another admin to re-add you (section 7). |
| I don't see the green bar on a page | You are not logged in, or your 8-hour login ran out. Log in at /admin-panel, then reopen the page. |
| My change isn't showing | Make sure you clicked **Save** and saw *Saved. Your changes are live.* Then refresh the page (Ctrl+F5 on Windows, Cmd+Shift+R on Mac). |
| I saved a mistake | **History** in the green bar, then **Restore** an earlier version (section 2). |
| A page has a yellow "site was updated" warning | The web developer changed that page. See section 2 before choosing; ask if unsure. |
| A picture shows as broken | It was probably deleted from Images. Edit the page and replace the picture. |
| Form emails aren't arriving | Check the top box on Forms & emails, then **Send test**, then the spam folder. Look in **Recent submissions**: *email failed* shows the error. A changed Google password or a deleted App Password means entering a new App Password. |
| The page says copying is off | The web developer needs to finish the go-live setup. |

**Good habits**

- Practice new things on the test site first.
- Save often; each save is a History point you can go back to.
- Give every picture a description.
- Log out on shared computers.
- Never share your password or the Gmail App Password by email or group chat.

**Who to contact:** for anything this guide doesn't cover, contact the site's web developer through nku@rotaryknk.org.
